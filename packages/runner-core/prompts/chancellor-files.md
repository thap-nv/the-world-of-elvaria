# The paths the owner's words name

Elvaria looked for them in the territories' working trees, without a model. Size every draft that reads or changes the files found from their numbers, as "How to estimate" says (about four characters make a token), and take its `scope_paths` from the paths it changes.

A path under "Not found" names no file git tracks in any territory: do not guess which file the owner meant. Unless the owner asks for that file to be created, either leave it out of the drafts, or, when the work needs it, name it in your one question (in the brief, for the council) and ask what the owner meant.
