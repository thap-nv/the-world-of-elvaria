## 6. Đa nền tảng Windows + macOS

(ADR 0015)

- **Mọi script là Node** (`scripts/*.mjs`, `tsx` cho TS; P0-08: không `tsx`, Node 24 chạy thẳng `.ts`). Không có file `.sh`, `.ps1`, `.cmd` trong repo (`pnpm docs:check` từ chối các đuôi này; husky hook gọi `node`/`pnpm`). Hook Claude khai dạng exec `node` + `args`; Gemini CLI tương tự (§3.7). Antigravity chạy chuỗi `command` qua `cmd /c` và làm hỏng dấu nháy (spike P1-12a), nên hook của nó khai `node elvaria-hook.mjs <Event>` tương đối với `.agents/`, nơi runner sinh một shim import hook thật bằng đường dẫn tuyệt đối (§3.7).
- **Đường dẫn**: `node:path` ở mọi nơi; trong file dữ liệu luôn dùng `/`; `toPortable(p)`/`fromPortable(p)` trong `store`; so sánh đường dẫn Windows không phân biệt hoa thường (`comparePath`); worktree `<repo>/.elvaria/worktrees/<quest-id>` với id 18 ký tự; `git config core.longpaths true`; `.gitattributes` `* text=auto eol=lf`.
- **Spawn**: `node:child_process.spawn` với `shell: false`; tìm executable kiểu `which` trong `elvaria doctor` và ghi đường dẫn tuyệt đối vào `kingdom.tools`; trên Windows nếu chỉ tìm thấy `.cmd` (npm shim) → đọc shim, chạy `node <js>` trực tiếp (không `shell: true` để khỏi lỗi quoting). (P0-08, người dùng chốt) `elvaria doctor` tìm CLI của từng tộc theo thứ tự `--tool <tộc>=<đường dẫn>` (máy phát triển không có `claude` lẫn `agy` trên PATH, cli-facts §0) → `tool.path` đã ghim nếu file còn → PATH (+ PATHEXT trên Windows); chạy `<CLI> --version` với env tối thiểu, ghim `{path, version, auth}` vào `tribes[].tool`; phiên bản hoặc đường dẫn khác bản đã ghim thì chỉ cảnh báo, `--pin` mới ghim lại, trừ khi file đã ghim không còn (extension VS Code cập nhật đổi thư mục của Claude Code): tộc không chạy được nên là lỗi, vẫn chờ `--pin`; tộc `antigravity` chưa có `terms_acknowledged_at` thì báo lỗi, `--acknowledge-terms <tộc>` ghi mốc giờ (ADR 0018); tộc tắt thì bỏ qua. Bảng adapter → tên chương trình (`claude_code: claude`, `antigravity: agy`, `gemini_cli: gemini`, `codex_cli: codex`) nằm trong `apps/cli` cho tới khi adapter có `doctor()` (P1-09, P1-12b); dò thư mục extension VS Code là việc của `runner-claude` (P1-09). (P0-08) Mọi test dựng repo git tạm (P1-07 `PlotManager`, runner, steward) chạy git **không** kèm biến `GIT_*`: hook pre-push của husky chạy test, mà git export `GIT_DIR` cho hook, nên một `git init`/`commit` kế thừa env sẽ đánh vào repo đang push (lần đầu push P0-08: `core.bare = true` trong config chung, `origin/HEAD` bị dời, commit rỗng trên nhánh; đã sửa tay). Mã chạy vốn an toàn vì spawn với env tối thiểu; helper test thì phải lọc env (`envWithoutGit` của `apps/cli/test/cli.ts`) và có test đặt `GIT_DIR` vào một repo ngoài để chứng minh. Kill tree: `taskkill /PID <pid> /T /F` (Windows) / SIGTERM → SIGKILL (macOS), gói trong `runner-core/src/process/kill-tree.ts`, test trên cả hai.
- **Thông báo**: `node-notifier` (kèm helper binary cho toast Windows và Notification Center macOS) sau interface `Bell { ring(n: Notice): Promise<void> }`; adapter `ConsoleBell` cho CI/sa bàn; web push ở giai đoạn 2 là adapter thứ ba.
- **File lock / atomic write**: `proper-lockfile` (retry, phát hiện lock cũ) cho `.state/steward.lock` và việc ghi quest; ghi file = ghi tmp cùng thư mục → `fs.rename` (Windows: thử lại khi `EPERM`/`EACCES`/`EBUSY` do antivirus, indexer hay một tiến trình đang đọc file). (P0-06) Thử lại theo **ngân sách thời gian** 10 s, mỗi lần chờ thêm 10 ms, tối đa 100 ms (cách của `graceful-fs`), thay cho "5 lần": với một reader đọc liên tục, 5 lần (~0,6 s) làm hỏng khoảng 1/200 lần ghi trong `concurrency.spec.ts` trên Windows (2/6 lượt chạy đỏ; sau khi đổi, 15/15 xanh).
- **Theo dõi event log**: không `fs.watch` (không tin cậy trên Windows; chokidar nặng); herald tail bằng polling `fs.stat` size 500 ms + cursor; sa bàn replay không cần watch. (P0-05) Cursor (`EventCursor`) là JSON thuần: với mỗi file ngày, offset byte sau dòng cuối đã đọc; giữ **hai** file ngày mới nhất, vì một dòng đóng dấu trước nửa đêm có thể được ghi sau khi file ngày mới đã có; ngày cũ hơn khóa nhỏ nhất là đã xong. Consumer lưu cursor cùng với thứ nó dựng từ event trong một lần ghi (eventlog không ghi `.state/`). Mỗi lần poll: liệt kê file ngày, `stat` từng file còn theo dõi, chỉ đọc phần mới. Reader để lại dòng chưa có `\n`; writer kết thúc dòng dở của một writer đã chết trước khi ghi dòng mới (đọc thêm 1 byte mỗi lần append), nên một crash chỉ mất đúng dòng đó; reader báo nó là `invalid_json`, hoặc `partial_line` khi file rời cursor mà vẫn còn dòng dở. Không fsync sau append (hook không đủ thời gian).
- **Ngày giờ**: `Intl` + offset thật của máy; tên file event theo ngày địa phương (`kingdom.tz`).
- **Home dir**: `os.homedir()`; `~/.elvaria/` cho kho bảo vật và config toàn cục; không giả định `%USERPROFILE%` hay `$HOME`.
- CI matrix `windows-latest`, `macos-latest`, `ubuntu-latest`; ca riêng của một OS dùng `it.runIf(process.platform === 'win32')`. (Chốt 2026-11-10) Matrix chạy tay khi cần, không ở mỗi PR (§7).
