# Desktop bell image

`elvaria-bell.png` is the placeholder Windows toast logo (128 × 128, gold E).
Replace this file with the final PNG artwork, at most 1024 × 1024 and 200 KB.
It stays outside `src` and `dist` so source runs, compiled runs and pinned git
worktrees resolve the same asset. Run `elvaria bell install` again to update the
durable copy used by Windows Notification Center.
